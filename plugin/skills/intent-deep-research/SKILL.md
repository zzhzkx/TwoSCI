# 意图驱动深度文献调研 (Intent Deep Research)

本技能专为科研人员的深度选题与综述调研设计，核心在于**先通过对话澄清研究意图，再展开精准深度检索**。

## 1. 意图澄清对话机制（必经步骤）

当用户提供基准种子文献（DOI、链接或论文名称）时，**不要立即发起盲目搜索**：

1. **解析种子画像**：调用 `create_research_brief` 解析种子文献的元数据、核心关键词与研究脉络，获取 `brief_id`。
2. **在对话中与用户澄清意图**：
   - **研究关注点**：向用户确认关注哪些具体维度（如算法原理、硬件约束、指标对比体系或应用场景）。
   - **边界与排除项**：确认是否有需要排除的技术路线（例如只看硅基，不看液晶；或只要星地链路，不看室内光通信）。
   - **期望交付卡片深度**：询问或根据意图确定最终输出卡片的检索深度：
     - `metadata`（快速速览）
     - `abstract`（标准摘要初筛，默认）
     - `fulltext`（深挖正文实验证据）

## 2. 深度检索与子 Agent 筛选

与用户达成一致后：

1. **多源深度检索**：调用 `search_intent_literature`，传入确认后的 `briefId`、`query` 与选择的 `search_scope`。
2. **摘要初筛**：将检索到的文献摘要分批派发给子 Agent 评估，调用 `save_screening` 记录 `include` / `exclude` / `maybe` 及判定理由。

## 3. 最终成果交付

- 意图检索的最终交付卡片与【基础检索】完全一致，取决于在对话中选定的检索深度（`metadata` / `abstract` / `fulltext`）。
- 意图的分析与筛选逻辑直接呈现在 Agent 与用户的交互对话中，确保交付界面简洁清晰。
