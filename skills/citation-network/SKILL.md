# 学术引文网络与演化拓扑追踪 (Citation Network)

本技能用于剖析一项关键学术工作的“前世今生”，建立清晰的技术演化脉络。

## 1. 核心追踪维度

1. **向前溯源：理论基石与前驱工作 (References)**
   - 这篇工作借鉴了谁的模型？
   - 核心物理图景与数学公式源自何处？
   - 制造工艺或芯片架构的原型是谁？

2. **向后追踪：最新应用与演进脉络 (Citing Papers)**
   - 后继学者在哪些方面对本文进行了改进（如提高精度、降低延迟、抑制扰动）？
   - 本文方案被应用到了哪些新的场景（如从室内扩展到星地、从单波束扩展到多波束）？
   - 最新的 Benchmark 突破了多少？

## 2. 工具调用与交付规范

调用 MCP 工具 `trace_citation_topology`：

```json
{
  "seed": "目标文献的 DOI、标题或会话记录 ID",
  "limit": 10
}
```

**交付成果必须包含**：
- **Mermaid 拓扑关系图**（直观展示 Ref -> Target -> Cite 关系）。
- **理论基石详细解析**（包含 DOI、作者、核心承接点）。
- **技术演化最新进展**（包含各篇施引文献的关键突破与对比）。
